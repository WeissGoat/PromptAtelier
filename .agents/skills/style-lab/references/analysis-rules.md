# 自定义画风分析规则

适配自 artist-style-reproduction 的投稿级分析经验；使用 PromptAtelier 图片索引/配方，不依赖旧项目目录、旧脚本或执行路径。

## 证据与元数据

以图片自身元数据为准：先 PNG 文本，缺失时使用已实现的 stealth 读取。只读源图，不将旧 skill 的元数据回写/复制目录行为搬来。缓存必须由直接图片读取产生，按 path、size、mtime_ns 失效；sidecar、旧 CSV 或旧分组不能替代图片证据。

以投稿为主要统计单位。多图投稿计一次；散图各自计一个来源。混合投稿拆图、跨组证据/抢救样本引用都不能重复放大投稿数。父组由成员来源去重汇总，不能简单把子组投稿数相加。

## 画风家族与变体

- 先找跨投稿稳定的画师栈/权重和风格组合，综合全栈、时间与视觉证据，不按孤立 tag 频率决定。
- 主类保持粗粒度，子组区分无 vibe、可恢复 vibe（参考图 hash）、缺参考及模型；有稳定差异的画师组合可单建风格变体。
- 分辨率、种子不分画风。sampler/steps/CFG/scheduler/数值强度/功能开关通常作参数变体或备注。
- 质量词、光影、realistic/anime coloring/cel shading 等零散修饰不能独立升为主类；漫画、单色等也要有跨投稿稳定的画师/风格依据，不能把一次性调味词或动作内容当风格。
- 角色、人数、服装、场景、姿势、表情和内容标签即使高频，通常也应留在主体/captions，不固定进可复用画风。
- 自动分组只是候选。修正合并或拆分时记录理由、证据图片与「充分/有限/待判断」，不编造精确置信百分数。

## 特殊来源

- 有 vibe 参数但缺内嵌图必须标缺参考，不能算 no_vibe。全投稿都缺参考时放在有依据的风格家族内待处理，不再按残留数值细拆。
- 同投稿至少一图有可恢复共享 vibe，其余图缺内嵌时，保留共享 vibe 分组并标记成员问题，不把混合投稿直接丢弃。
- 混合投稿有普通文生图时正常分析可用图，img2img/inpaint/add_original 作成员限制。
- 全投稿特殊来源但有可恢复 vibe 时，保留风格/vibe 归属并说明仍缺底图；无可恢复 vibe 时可放顶层特殊来源归档。不能声称仅靠提示词能复刻底图携带的画风。
- 真正可抢救的 no_vibe 样本须自身是普通文生图、无内嵌参考且无 vibe 参数。记录原来源/抢救理由，以引用关联，不复制图片，不增加投稿统计。
- 待判断是复查队列。有图片证据支持某家族就归回；确实无法判断的写明原因，不编造标签或参考图。

## 代表图与配方

综合投稿占比、近期连续性、参数/提示词稳定性及可复现性，优先主流家族中较新且完整的普通文生图，不机械选最新或最常见的一张。避开缺参考、缺底图、无种子/模型/尺寸的样本；没有完整代表图就保留待处理组/草稿。

每个可用叶子组默认建立一份完整划分配方，明确证据支持不同稳定参数/画师变体时可多份。模型/参数/vibe 来自具体代表图，不能把不同图片的参数和参考图随意混合。保留全部 captions、负面、位置、权重及项目质量控制 flags；生成宽高与种子是测试设置。

保存前校验：组 id 稳定、两级无环、成员只在一个叶子组、代表图属于该组、证据图片存在、锁定项未被覆盖、统计去重、特殊来源语义正确。准备阶段到预览/保存配方结束，不原参重生，不测试出图。
